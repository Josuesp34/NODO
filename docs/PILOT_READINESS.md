# Condiciones para abrir un piloto

No abrir acceso a atletas reales hasta completar estas condiciones:

- Identidad multirol, relaciones entrenador-atleta y pruebas de acceso cruzado.
- Invitación segura, recuperación de cuenta, HTTPS, secretos administrados y rate limiting.
- Actividades asociadas obligatoriamente al atleta, deduplicación e historial auditable.
- Consentimiento, exportación/borrado de datos y política de retención.
- Backups automáticos y una restauración comprobada.
- Despliegue reproducible de API, worker, base, almacenamiento de archivos y monitoreo básico.
- Pipeline persistente para sincronización y recomendaciones.
- Registro de auditoría para cambios de plan, molestias y aprobaciones.
- Prueba de carga y recorrido completo con un equipo pequeño de prueba.

El piloto inicial no debe prometer diagnóstico médico, prevención de lesiones, predicción exacta de rendimiento ni ajustes automáticos de entrenamiento.
